# GlucoVibes Clinic · Dashboard del paciente (demo)

Prototipo estático con **datos simulados**: tres perfiles de paciente (longevidad, pérdida de peso, rendimiento) para usar en consulta.

- `index.html` — Longevidad · salud preventiva
- `peso.html` — Pérdida de peso · obesidad
- `rendimiento.html` — Rendimiento deportivo

No necesita servidor ni dependencias: abre `index.html` en el navegador, o publícalo en GitHub Pages
(repositorio → Settings → Pages → Deploy from branch → `main` / root).

**No subir nunca datos reales de pacientes a un alojamiento público.**
